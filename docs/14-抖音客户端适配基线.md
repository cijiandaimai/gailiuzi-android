# 14 抖音客户端适配基线

## 1. 资料基线

本轮适配使用用户提供的 Android 客户端公开资料快照进行离线校验：

| 项目 | 校验值 |
|---|---|
| 包名 | `com.ss.android.ugc.aweme` |
| 客户端版本 | `39.5.0` |
| Version Code | `390501` |
| Min / Target / Compile SDK | `23 / 34 / 35` |
| 安装包 SHA-256 | `8179f44a0337e455a03e48630369bd461f2087d6feeb5d793cc3554cd5b36d43` |

该基线用于页面识别、风险停机和回归测试，不把客户端内部类名、Deep Link 或网络协议视为官方稳定 API。

## 2. 已校验页面指纹

| 业务页面 | 已观察类名特征 | 改流子处理 |
|---|---|---|
| 搜索 | `SearchResultActivity` / `SearchPartShowResultActivity` / `HotSearchAndDiscoveryActivity` | 识别搜索场景，品牌任务优先匹配已审核关键词 |
| 视频详情 | `DetailActivity` / `SingleTaskDetailActivity` / `UltraDetailActivity` / `VideoPlayActivity` | 建立视频、作者、目标评论和对话上下文 |
| 评论管理 | `CommentManagerActivity` / `CmtReplyDetailActivity` | 前台模式处理自有账号评论 |
| 评论详情 | `CommentFeedActivity` / `CommentMergeInfoActivity` / `NotificationDetailActivity` | 识别评论与父级回复对话 |
| 互动通知 | `LikeUserListActivity` / `FansDetailActivity` | 只用于发现事件，不触发批量回关或点赞 |
| 用户主页 | `UserProfileActivity` | 只读取与当前任务相关的公开信息 |
| 开放平台授权 | `SchemaAuthorizedActivity` / `AwemeAuthorizedActivity` | 识别授权过程，不记录凭据正文 |
| 登录/验证/封禁 | `DYLoginActivity` / `DyVerifyActivity` / `TwoStepAuthActivity` / `BannedDialogActivity` | 立即停止当前辅助流程并交还用户 |

## 3. 官方 API 优先级

建议申请并按实际审核结果保存以下 Scope：

```text
video.list
video.data
video.comment
video.search
video.search.comment
```

执行通道：

```text
自有视频评论：官方 API
已审核品牌关键词搜索：官方 API
客户端页面发现：Android 可见辅助
客户端 UI 回复兜底：草稿 + 人工确认
```

## 4. 执行政策

- 前台模式、L2、P3 低风险且已获官方写入能力时，可进入确定性官方 API 执行通道。
- 通过客户端 UI 兜底时，始终返回 `DOUYIN_UI_MANUAL_CONFIRMATION_REQUIRED`。
- 逛街或公关模式的社区互动即使具有官方能力，也返回 `DOUYIN_DISCOVERY_APPROVAL_REQUIRED`。
- P0/P1 内容一律创建事件并人工升级，不自动回击。
- 登录、二次验证、封禁或风险提示页触发 `SAFETY` 事件并立即停止当前辅助流程。

## 5. AI 回复约束

1. 仅回应自有内容或已审核的品牌、产品、门店和活动关键词场景。
2. 不在无关视频下跨话题引流，不使用重复刷屏话术。
3. 区分视频作者、评论发起者和跟评访客。
4. 草稿必须引用对方的实际问题或对话上下文，不根据头像推断敏感属性。
5. 不编造价格、效果、服务记录或调查结论。

## 6. 版本回归

- 客户端版本更新时重新校验页面类名指纹。
- 未识别页面只上报诊断，不实施写操作。
- 不依赖客户端私有接口、请求签名、风控字段或内部 Deep Link 承担生产业务。
- 适配器页面识别失败率超过阈值时自动降级到只读发现。
