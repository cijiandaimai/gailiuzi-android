# 13 小红书客户端适配基线

## 1. 资料基线

本轮适配使用用户提供的 Android 客户端公开资料快照进行离线校验：

| 项目 | 校验值 |
|---|---|
| 包名 | `com.xingin.xhs` |
| 客户端版本 | `9.37.3` |
| Version Code | `9373801` |
| Target SDK | `35` |
| 主入口 | `com.xingin.xhs.index.v2.IndexActivityV2` |
| 统一路由入口 | `com.xingin.xhs.routers.RouterPageActivity` |

该基线只用于页面识别、能力分级和回归测试，不将客户端内部实现视为稳定接口。

## 2. 已验证页面指纹

| 业务页面 | 已观察类名特征 | 改流子处理 |
|---|---|---|
| 首页 | `IndexActivityV2` | 只读识别 |
| 搜索 | `GlobalSearchActivity` / `GlobalSearchHalfScreenActivity` | 用户主动搜索，结果进入机会筛选 |
| 笔记详情 | `NoteDetailActivity` / `DetailFeedActivity` / `MediumVideoPageActivity` | 读取当前可见上下文，生成草稿 |
| 评论输入 | `NoteCommentActivity` | 标记为可操作页，但最终发送仍由人工点击 |
| 评论记录 | `HistoryCommentActivity` | 用于自有互动回溯 |
| 互动通知 | `MsgNotificationV2Activity` / `FoldCommentActivity` | 用于前台模式发现 |
| 个人主页 | `MyUserActivity` / `NewOtherUserActivity` / `FloatingOtherUserActivity` | 仅读取与当前任务相关的公开信息 |
| 登录/风险提示 | 类名包含 `Login` / `RestrictAccessActivity` | 停止当前流程，交还用户 |

## 3. 能力边界

```text
电商商家能力：官方开放平台，按资质和 Scope 接入
社区搜索/阅读：用户可见的 Android 辅助
社区回复：生成草稿，人工确认与发送
自动点赞/收藏/关注/私信：不可用
```

小红书请求即使标记 `officialWriteCapability=true`，也不会越过 `InteractionPolicy`。社区内容始终返回 `DRAFT_FOR_APPROVAL`，并附带：

- `XHS_COMMUNITY_MANUAL_SEND_ONLY`
- `XHS_NO_CONFIRMED_OFFICIAL_COMMUNITY_WRITE_API`

## 4. 无障碍实现调整

- 按完整 Activity 类名做稳定页面分类，不依赖易变文案。
- `TYPE_WINDOW_CONTENT_CHANGED` 上报通用 View 类名时，继承最近一次已识别的小红书页面状态。
- 删除 `canPerformGestures`，当前版本不申明手势执行能力。
- 设备动态只记录页面类型和类名摘要，不写入通知正文、账号密码或长期个人画像。

## 5. AI 回复约束

小红书草稿额外注入以下指令：

1. 不伪装普通消费者；
2. 不编造体验、价格、效果或调查结论；
3. 不引导站外联系；
4. 不在无关笔记下使用重复广告话术；
5. 必须参考笔记、目标评论和父级对话上下文。

## 6. 回归规则

- 客户端版本变化时重新校验页面指纹。
- 页面未识别时只记录诊断，不产生写操作。
- 连续识别失败超过阈值后自动关闭小红书辅助写入入口。
- 任何登录、验证码、风控或账号异常页立即交还用户处理。
