# 15 快手客户端适配基线

## 1. 资料基线

本轮使用用户提供的快手 Android 客户端公开资料快照进行离线校验：

| 项目 | 校验值 |
|---|---|
| 包名 | `com.smile.gifmaker` |
| 客户端版本 | `14.6.10.49019` |
| Version Code | `49019` |
| Min / Target / Compile SDK | `21 / 30 / 30` |
| 主入口 | `com.yxcorp.gifshow.HomeActivity` |
| 安装包 SHA-256 | `314c15f4ef98a0f114cc5730a29f006472d39cec14f9734c35b4e7b6772ee8c2` |

该基线只用于客户端包识别、可见页面分类、风险停机和回归测试。客户端内部类名、Deep Link、Provider、网络协议和签名实现均不视为官方稳定 API。

## 2. 页面指纹

| 业务页面 | 已观察类名特征 | 改流子处理 |
|---|---|---|
| 首页 | `HomeActivity` | 建立快手页面会话 |
| 搜索 | `SearchActivity` / `SearchGroupResultActivity` / `SearchVerticalSceneActivity` | 只处理已审核品牌任务，商家搜索等无关同名页不误判 |
| 作品详情 | `PhotoDetailActivity` / `PhotoDetailListenVideoActivity` / `TopicDetailActivity` | 建立作品、作者、目标评论和父级对话上下文 |
| 评论上下文 | `CommentAlbumActivity` / `ImageDetailActivity` / `EmotionDetailActivity` | 识别评论附件与表情详情，不自动发布 |
| 互动通知 | `NewFansActivity` / `NoticeBoxDetailActivity` | 只用于发现事件，不触发批量点赞、回关或私信 |
| 用户主页 | `MyProfileActivity` / `UserProfileActivity` | 只读取当前任务必要的公开信息 |
| 开放平台授权 | `RouteHandlerActivity` / `KwaiH5LoginActivity` / `AuthActivity` | 识别授权流程，不记录授权码、Token 或凭据正文 |
| 登录/验证/封禁 | `LoginActivity` / `VerifyPhoneActivity` / `UserBannedActivity` / `AccountRiskCheckActivity` | 立即停止辅助流程并交还用户 |

## 3. 官方开放能力

快手开放平台已公开 OAuth、授权用户信息与自有作品信息能力。当前默认按最小必要原则预填：

```text
user_info
user_video_info
```

每个商户必须以快手实际审核通过并由 Token 返回的 Scope 为准。未在公开文档中确认可用的社区评论读取、评论回复和公开搜索写入能力，不得由官方能力开关推断为可执行。

官方资料：

- [快手开放平台授权](https://open.kuaishou.com/platform/openApi?menu=12)
- [快手授权用户公开信息](https://open.kuaishou.com/platformDocs/openAbility/userInformation/publicInformation)
- [快手开放平台服务端 SDK](https://open.kuaishou.com/platformDocs/develop/serverSDK)

## 4. 执行政策

```text
授权用户信息：官方 API
自有作品数据：官方 API
社区搜索与作品定位：Android 可见辅助
评论草稿：Android 可见辅助
评论发布：人工确认
批量点赞/关注/私信：不可用
```

- 快手社区互动始终返回 `KUAISHOU_COMMUNITY_MANUAL_SEND_ONLY`。
- 即使业务请求将 `officialWriteCapability` 设为 `true`，也不能解锁未确认的评论写入能力。
- P0/P1 内容一律人工升级。
- 登录、验证、封禁或账号风险页触发 `SAFETY` 事件并停止当前流程。

## 5. AI 草稿约束

1. 仅处理自有作品或与已审核品牌任务直接相关的内容。
2. 必须同时基于作品、作者、目标评论和父级对话生成草稿。
3. 不根据头像或昵称推断敏感属性，不伪装消费者或编造体验。
4. 不在无关作品下跨话题引流，不使用重复刷屏话术。
5. 不编造价格、效果、服务记录、调查结论或承诺。

## 6. 版本回归

- 快手客户端升级时重新校验页面类名指纹。
- 未识别页面只上报诊断，不实施写操作。
- 页面识别失效时降级为通知发现和人工导航。
- 不依赖客户端私有 Provider、Deep Link、请求签名或风控字段承担生产业务。
