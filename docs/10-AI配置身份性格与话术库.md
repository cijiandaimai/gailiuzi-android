# 10 AI API、身份性格与预置话术配置

## 1. 版本范围

本功能从改流子 `0.2.0` 开始提供，包含：

- GPT/OpenAI Responses API。
- 豆包/火山方舟 Responses API。
- 首选模型与失败回退。
- API连接测试。
- Android Keystore密钥加密。
- AI身份、角色、性格和语气配置。
- 预置话术库开关、增删改、优先级和关键词匹配。
- 抖音、美团、小红书官方开放平台参数入口。

## 2. 默认API配置

| 提供商 | Base URL | 默认模型 |
|---|---|---|
| GPT/OpenAI | `https://api.openai.com/v1` | `gpt-5-mini` |
| 豆包/火山方舟 | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seed-2-0-lite-260215` |

两个提供商都使用 `/responses` 请求路径。用户可以修改Base URL和模型名称，以适配代理网关、企业网关或后续模型版本。

## 3. 主备模型

用户可以选择GPT或豆包作为首选提供商。

调用流程：

```text
首选提供商已启用且密钥有效
→ 调用首选提供商
→ 调用失败
→ 尝试另一个已启用且配置完成的提供商
→ 全部失败后返回合并错误
```

未启用、未配置密钥或模型/Base URL为空的提供商不会进入调用队列。

## 4. 密钥存储

- API Key和平台Client Secret不写入普通配置文件。
- 使用Android Keystore生成AES/GCM设备密钥。
- 加密后的数据保存在独立SharedPreferences中。
- App界面不会回显已保存密钥。
- 新密钥输入框留空时保留原密钥。
- 支持单独清除每个提供商或平台的密钥。

## 5. 身份性格

默认身份：

```text
称呼：小改
角色：商家客服与口碑运营助手
性格：专业温和
语气：真诚、简洁、有分寸
```

内置性格：

- 专业温和。
- 亲切自然。
- 简洁可靠。
- 热情活泼。
- 公关沉稳。

关闭“身份性格”后，系统使用不带品牌人格的通用专业回复指令。

## 6. 预置话术库

默认开启。内置：

- 感谢认可。
- 门店位置咨询。
- 价格项目咨询。
- 预约咨询。
- 服务体验反馈。

每条话术包含：

- 名称。
- 意图标签。
- 关键词。
- 话术正文。
- 0～100优先级。
- 启用状态。
- 可选平台限制。

匹配顺序：

```text
启用状态
→ 平台范围
→ 意图标签
→ 关键词命中
→ 话术优先级
→ 选择最高分话术
```

匹配成功后，话术正文写入模型指令，要求AI优先以话术为答案基础，只对称谓和上下文做必要调整。

## 7. 回复测试台

AI配置页面提供回复测试台，可以：

- 选择抖音、美团或小红书。
- 输入模拟评论。
- 调用当前首选模型。
- 显示实际回复。
- 显示最终使用的模型。
- 显示命中的预置话术ID。

## 8. 平台官方API配置

### 抖音

默认Base URL：`https://open.douyin.com`。

默认申请范围：

- `video.comment`：企业号评论管理。
- `video.search`：审核通过的品牌关键词视频管理。

平台API用于评论同步、品牌相关内容搜索和经过授权的回复，不替代GPT或豆包的文本理解与生成。

### 美团/大众点评

提供Base URL、App Key、Secret和Scope配置入口。具体评价能力按商家主体、服务商资质和平台实际开放权限启用。

### 小红书

提供开放平台配置入口。社区评论自动回复能力只有在取得正式开放权限后才启用；否则继续使用草稿和人工确认路径。
