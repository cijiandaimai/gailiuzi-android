# 隐私与无障碍使用说明

## 1. 数据边界

改流子不保存抖音、快手、美团/大众点评、小红书账号密码。用户在平台官方 App 内自行登录。

原型版本在本机保存的业务设置包括：运行模式、AI 提供商配置、助手性格、话术库、门店组织、知识库和纠错样本。API Key、Client Secret 和网关 Token 使用 Android Keystore AES-GCM 加密保存。

## 2. 无障碍服务用途

无障碍服务仅用于识别用户已打开的受支持平台页面、记录页面发现事件并辅助生成待审核草稿。当前版本不自动点击发送、不自动输入评论、不读取或保存平台密码。

标准处理链路为：

```text
发现 → 生成草稿 → 合规校验 → 人工确认 → 用户在平台内主动发送
```

## 3. AI 与知识库

用户发起 AI 生成或知识库学习时，相关 Prompt、商家知识片段和待处理内容可能发送给用户选择的模型提供商或企业 API 网关。管理员应仅上传有权处理的资料，并在发送前移除不必要的个人信息。

## 4. 用户控制

- 可在系统设置中随时关闭无障碍服务和通知访问权限。
- 可在应用内停止前台辅助服务。
- 删除应用数据或卸载应用可清除本机配置；外部模型提供商处理的数据按对应服务条款执行。

## 5. 敏感属性

不根据头像、昵称或发言推断年龄、性别、健康、收入、种族、宗教等敏感属性。潜客评分只使用与当前业务有关的公开需求信号和对话上下文。
