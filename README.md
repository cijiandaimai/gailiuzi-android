# 改流子（Android）

改流子是一款面向抖音、美团/大众点评和小红书的 Android 服务行业口碑运营助手。本仓库包含可构建的 Android 应用和完整项目方案。

## 当前应用

- 应用名称：改流子
- Application ID：`com.gailiuzi.app`
- 当前版本：`0.4.0 (4)`
- 最低系统：Android 12 / API 31
- 编译与目标版本：Android 16 / API 36
- UI：Kotlin + Jetpack Compose + Material 3

### 功能状态

#### ✅ 已实现并经本地构建验证

- 工作台、设备动态和设置三个主页面。
- 前台、逛街、公关三个模式开关。
- L0 监控、L1 草稿、L2 半自动等级。
- 无障碍权限和通知监听权限入口。
- 可停止的前台辅助服务。
- 抖音、美团/大众点评、小红书页面事件观察。
- 支持平台通知事件发现。
- 潜在客户评分和互动策略核心逻辑。
- 高风险升级、小红书人工确认和上下文不足阻断策略。
- GPT/OpenAI与豆包/火山方舟 Responses API 配置、连接测试和主备切换。
- API Key与平台Client Secret通过Android Keystore加密保存。
- AI身份、角色、性格、语气和自定义指令配置。
- 可开关、可编辑的预置话术库，开启后优先匹配话术。
- AI回复测试台，可验证模型、身份和话术匹配结果。
- 抖音、美团和小红书官方开放平台配置入口。
- 医疗功效、绝对化承诺、价格、个人信息及商家自定义禁用词风控。
- GPT、豆包、千问、Gemini、DeepSeek和自定义OpenAI兼容模型接入。
- 商户自选主控模型，按顺序自动故障回退。
- 结构化 AI 错误分类、429/5xx/超时重试和有界指数退避。
- 仅允许不含内嵌凭据的 HTTPS 模型与网关地址。

#### 🟡 本地原型实现，尚未完成多租户生产验证

- 面向美容、按摩、SPA 等服务行业的总部—区域—门店三级组织管理。
- 线上平台评价、线上商品评价和线下门店反馈的统一口碑数据模型。
- 商家专属知识库上传、本地索引、模型提炼、人工复核与纠错样本。
- 知识按总部、区域和门店继承检索，生成回复时注入可核实事实。
- 不内置 VPN 的“绿色通道”配置：官方直连、智能路由、商户企业 API 网关和网络诊断。

#### 📋 规划中

- 多租户业务后端、商户登录、设备绑定和数据权限隔离。
- 服务端模型路由、短期业务令牌、用量计费和审计日志。
- Room/DataStore 持久化、后台同步、灰度发布和崩溃监控。

当前版本不会自动发布评论，发送前仍由平台权限、自动化等级和合规策略共同控制。

## 构建

环境要求：JDK 17、Android SDK 36、Gradle Wrapper。

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

当前工作区路径含中文。在 Windows 上执行 JVM 单元测试时建议从 ASCII 路径或目录联接构建：

```powershell
New-Item -ItemType Junction -Path D:\11\AI_PR -Target D:\11\AI公关部
Set-Location D:\11\AI_PR
.\gradlew.bat clean testDebugUnitTest assembleDebug
```

Debug APK：`app/build/outputs/apk/debug/app-debug.apk`

## 关键架构决策

- 平台官方 API 优先，Android UI 自动化只用于官方能力缺口。
- 不保存平台账号密码；账号由用户在平台官方 App 内自行登录。
- 大模型负责理解和生成，确定性状态机负责执行。
- 任何发送动作都必须经过规则引擎；中高风险内容必须人工确认。
- 小红书社区互动默认采用“发现 + 草稿 + 人工确认”，不默认开放无人值守自动评论。
- 所有动作必须可追踪、可复核、可停止、可回滚到人工接管。
- 逛街和公关模式先筛选内容与评论，再对入围对象读取公开主页和对话上下文，不对所有用户无差别互动。
- 只根据公开、与当前业务相关的信息判断需求意图，不通过头像推断年龄、性别、健康、收入等敏感属性。
