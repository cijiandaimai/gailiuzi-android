# 改流子（Android）

改流子是一款面向抖音、美团/大众点评和小红书的 Android 商家口碑运营助手。本仓库包含可构建的初版 Android 应用和完整项目方案。

## 初版应用

- 应用名称：改流子
- Application ID：`com.shangbaobao.app`
- 当前版本：`0.1.0 (1)`
- 最低系统：Android 12 / API 31
- 编译与目标版本：Android 16 / API 36
- UI：Kotlin + Jetpack Compose + Material 3

已实现：

- 工作台、设备动态和设置三个主页面。
- 前台、逛街、公关三个模式开关。
- L0 监控、L1 草稿、L2 半自动等级。
- 无障碍权限和通知监听权限入口。
- 可停止的前台辅助服务。
- 抖音、美团/大众点评、小红书页面事件观察。
- 支持平台通知事件发现。
- 潜在客户评分和互动策略核心逻辑。
- 高风险升级、小红书人工确认和上下文不足阻断策略。

初版不会自动发布评论，当前重点是完成权限、状态机、观察、风控和后续平台适配所需的工程底座。

## 构建

环境要求：JDK 17、Android SDK 36、Gradle Wrapper。

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

当前工作区路径含中文。在 Windows 上执行 JVM 单元测试时建议从 ASCII 路径或目录联接构建：

```powershell
New-Item -ItemType Junction -Path D:\11\AI_PR -Target D:\11\AI公关部
Set-Location D:\11\AI_PR
.\gradlew.bat clean testDebugUnitTest assembleDebug
```

Debug APK：`app/build/outputs/apk/debug/app-debug.apk`

## 关键架构决策

- 平台官方 API 优先，Android UI 自动化只用于官方能力缺口。
- 不保存平台账号密码；账号由用户在平台官方 App 内自行登录。
- 大模型负责理解和生成，确定性状态机负责执行。
- 任何发送动作都必须经过规则引擎；中高风险内容必须人工确认。
- 小红书社区互动默认采用“发现 + 草稿 + 人工确认”，不默认开放无人值守自动评论。
- 所有动作必须可追踪、可复核、可停止、可回滚到人工接管。
- 逛街和公关模式先筛选内容与评论，再对入围对象读取公开主页和对话上下文，不对所有用户无差别互动。
- 只根据公开、与当前业务相关的信息判断需求意图，不通过头像推断年龄、性别、健康、收入等敏感属性。
